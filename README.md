# 1Z Plugin Marketplace

Repositório local para gerenciar seus plugins. Cada plugin fica em plugins/<slug>/.

## Plugins

- **cerebro-memoria**: plugin de memória persistente em Obsidian (SKILL.md, eferences/, scripts/).

## Como usar

2. Mantenha plugins/marketplace.json atualizado com os metadados.
